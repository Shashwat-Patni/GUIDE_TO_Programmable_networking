# Programmable Networking and SDNs — Start Here

New to networks, SDNs or P4? Start with the
**[Beginners Guide to Programmable Networking and SDNs](Beginners_Guide_to_Programmable_Networking_and_SDNs.md)**.

It is a self paced guide, so go at ur own speed. No deep networking knowledge is needed to begin.

## What the guide covers

1. **Understanding networks:** the OSI layers and the basic terms
2. **SDNs, control planes and data planes:** what SDN is and how the two planes split the work
3. **The need for P4:** why a programmable data plane, and how it differs from OpenFlow
4. **P4 — its models, architectures and compilers:** v1model, PSA, PNA, TNA, p4c and BMv2
5. **P4 tutorials for a hands on experience:** VM setup, Mininet and the official P4 tutorials

The main aim is to understand and run the different P4 tutorials. Sections 1 to 4 give u enough
background to know what u are doing when u get there, so skim them and get to the tutorials.

## How to use it

- Go through the sections in order. Each one has a few short reads and a table of the terms u
  should know before moving on.
- Links marked as long or reference only don't need to be read in full. Come back to them when
  u need them.
- Try every tutorial urself before opening its solution.
- The books at the end are optional. Use them when u want the full picture of a topic.
